# Astral Scythe

Full-colour Python 3 neon orbital-harvest arcade for ElbowOS.

A gold core sits in a violet well. Steer the orbiting scythe.
Reap teal / gold / magenta shards. Rose thorns break the combo.
A / D orbit. W / S change radius. Space slashes.

## Play

```
pip install -r requirements.txt
python3 astral_scythe.py --play
```

## Record a 9:16 reel

```
python3 astral_scythe.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
